## Коллекция Postman

Коллекция Postman содержит API-запросы для описанных в проекте тестовых сценариев.

Коллекция использует переменные и автоматически сохраняет `bookingId`, полученный в ответе на `POST /booking`. Благодаря этому запросы не зависят от конкретного идентификатора бронирования.

> Примечание: Restful Booker — публичный тестовый стенд, данные на котором периодически сбрасываются. Поэтому идентификаторы бронирований, полученные во время предыдущих запусков тестов, могут стать недоступными.
