# Получение списка бронирований — Test Cases

## Base URL: https://restful-booker.herokuapp.com

## Endpoint
`GET /booking`

## Тестовые сценарии
- Получение списка бронирований и проверка структуры элементов списка
- Фильтрация по имени
- Фильтрация по фамилии
- Фильтрация по дате заезда
- Фильтрация по дате выезда
- Комбинация фильтров

## TC-LIST-001 — Получение списка бронирований

**Priority:** High  
**Type:** Functional / Positive  
**Method:** `GET`  
**Endpoint:** `/booking`

### Предусловия
- Restful Booker API доступен.
- В системе существуют бронирования.

### Тестовые данные
Не требуются.

### Шаги
1. Отправить `GET` запрос на `/booking`.
2. Проверить HTTP status code.
3. Проверить тип response body.
4. Проверить структуру элементов списка.
5. Проверить наличие поля `bookingid` в элементах списка.

### Ожидаемый результат
- API возвращает `200 OK`.
- Response body содержит список бронирований.
- Response body имеет формат массива JSON.
- Каждый элемент списка является объектом.
- Каждый объект содержит поле `bookingid`.
- `bookingid` содержит идентификатор бронирования.

### Результат выполнения
**Status:** Passed

**Фактический результат:**
API вернул `200 OK`.
Response содержит массив бронирований. Каждый элемент массива представлен объектом с полем `bookingid`.

### `TC-LIST-002 — Фильтрация бронирований по имени`

**Priority:** High  
**Type:** Functional / Positive  
**Method:** `GET`  
**Endpoint:** `/booking?firstname={name}`

### Предусловия
- Restful Booker API доступен.
- В системе существуют бронирования.
- Предварительно создано бронирование

### Тестовые данные
Значение из `firstname` по предварительно созданному бронированию вставить в Endpoint

### Шаги
1. Отправить `GET` запрос на `/booking?firstname={name}`, где `{name}` соответствует значению `firstname` из созданного ранее бронирования.
2. Проверить HTTP status code.
3. Проверить наличие поля `bookingid` в response body.

### Ожидаемый результат
- API возвращает `200 OK`.
- Response body возвращает результат по всем бронированиям с заданным именем.
- Каждый объект массива в теле ответа содержит поле `bookingid` с идентификатором бронирования.

### Результат выполнения
**Status:** Passed

**Фактический результат:**
API вернул `200 OK`.
Response содержит массив бронирований с заданным именем. Каждый объект массива содержит `bookingid`.
