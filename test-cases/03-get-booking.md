# Get Booking — Test Cases

## Base URL: https://restful-booker.herokuapp.com

## Тестовые сценарии
- Получение бронирования по ID, созданному через POST
- Получение несуществующего бронирования
- Передача некорректного ID

## TC-GET-001 — Получение бронирования по ID, созданному через POST

**Priority:** High  
**Type:** Positive 
**Endpoint:** `GET /booking/{id}`

### Предусловия
- Restful Booker API доступен.
- Создано новое бронирование с помощью `POST /booking`.
- Полученный `bookingid` сохранён.

### Тестовые данные
Использовать `bookingid`, полученный в результате создания бронирования.

### Шаги
1. Отправить `GET` запрос на `/booking/{id}`, указав ID предварительно созданного бронирования.
2. Проверить HTTP status code.
3. Проверить структуру response body.
4. Проверить наличие всех ожидаемых полей бронирования.
5. Проверить соответствие данных ожидаемому бронированию.

### Ожидаемый результат
- API возвращает HTTP status code `200 OK`.
- Response содержит данные запрошенного бронирования.
- Response содержит поля:
  - `firstname`
  - `lastname`
  - `totalprice`
  - `depositpaid`
  - `bookingdates`
  - `additionalneeds`
- Значения полей соответствуют запрошенному бронированию, созданному ранее.

### Результат выполнения

**Status:** Passed

**Фактический результат:**

API вернул `200 OK` и данные существующего бронирования. Данные бронирования соответствуют данным, переданным при его создании.

## TC-GET-002— Получение бронирования по несуществующему ID

**Priority:** High  
**Type:** Functional / Negative  
**Endpoint:** `GET /booking/{id}`

### Предусловия
- Restful Booker API доступен.
- Бронирование с указанным ID отсутствует.

### Тестовые данные
`bookingid: 9999`

### Шаги
1. Отправить `GET /booking/9999`.
2. Проверить HTTP status code.
3. Проверить response body.

### Ожидаемый результат
- API не возвращает данные бронирования.
- API возвращает соответствующий HTTP status code для несуществующего ресурса.
- Response содержит информацию об отсутствии запрошенного бронирования.

### Результат выполнения
**Status:** Passed

**Фактический результат:**
API вернул `404 Not Found`. Данные бронирования не возвращены.
