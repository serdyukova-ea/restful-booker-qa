# Get Booking — Test Cases

## TC-GET-001 — Получение существующего бронирования по ID

**Priority:** High  
**Type:** Positive  
**Endpoint:** `GET /booking/{id}`

### Предусловия
- Restful Booker API доступен.
- Создано новое бронирование с помощью `POST /booking`.
- Полученный `bookingid` сохранён.

### Тестовые данные
Использовать `bookingid`, полученный в результате создания бронирования.

### Шаги
1. Отправить `GET` запрос на `/booking/{id}`, указав ID предварительно созданного бронирования.
2. Проверить HTTP status code.
3. Проверить структуру response body.
4. Проверить наличие всех ожидаемых полей бронирования.
5. Проверить соответствие данных ожидаемому бронированию.

### Ожидаемый результат
- API возвращает HTTP status code `200 OK`.
- Response содержит данные запрошенного бронирования.
- Response содержит поля:
  - `firstname`
  - `lastname`
  - `totalprice`
  - `depositpaid`
  - `bookingdates`
  - `additionalneeds`
- Значения полей соответствуют запрошенному бронированию, созданному ранее.

### Результат выполнения

**Status:** Passed

**Фактический результат:**

API вернул `200 OK` и данные существующего бронирования. Данные соответствуют ожидаемому бронированию.
