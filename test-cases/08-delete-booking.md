## TC-DELETE-001 — Удаление существующего бронирования

**Priority:** High  
**Type:** Functional / Positive  
**Method:** `DELETE`  
**Endpoint:** `/booking/{id}`

### Предусловия
- Restful Booker API доступен.
- Предварительно создано бронирование.
- Получен действующий токен авторизации.

### Тестовые данные
Не требуются.

### Шаги
1. Отправить DELETE `/booking/{id}` по предварительно созданному бронированию.
2. Проверить HTTP status code.
3. Проверить данные response body.
4. Отправить GET `/booking/{id}` для только что удаленного бронирования.
5. Проверить HTTP status code и response body запроса GET.

### Ожидаемый результат
- DELETE возвращает `200 OK`.
- GET `/booking/{id}` по тому же id возвращает `404 Not Found`
- Бронирование удалено.
- 
### Результат выполнения
**Status:** Passed

**Фактический результат:**
API вернул `201 Created`.
Последующий GET `/booking/{id}` вернул `404 Not Found` и подтвердил удаление бронироавния.
