## TC-FULL_UPD-001 — Обновление бронирования с полным набором полей

**Priority:** High  
**Type:** Functional / Positive  
**Method:** `PUT`  
**Endpoint:** `/booking/{id}`

### Предусловия
- Restful Booker API доступен.
- Предварительно создано бронирование.
- Получен действующий токен авторизации.

### Тестовые данные
Не требуются.

### Шаги
1. Отправить GET `/booking/{id}` по предварительно созданному бронированию и сохранить исходные данные.
2. Отправить PUT `/booking/{id}`, поменяв значения каждого поля на другие валидные данные.
3. Проверить HTTP status code.
4. Проверить данные response body.
5. Отправить GET `/booking/{id}` для того же `bookingid`.
6. Сравнить данные из GET с данными, переданными в PUT.

### Ожидаемый результат
- API возвращает `200 OK`.
- Response PUT содержит обновлённые данные.
- GET `/booking/{id}` возвращает 200 OK.
- Данные бронирования после повторного выполнения GET соответствуют данным, переданным в запросе PUT.

### Результат выполнения
**Status:** Passed

**Фактический результат:**
API вернул `200 OK`.
Response содержит переданные при обновлении данные. Последующий GET `/booking/{id}` вернул 200 OK и подтвердил сохранение изменений. Фактические значения соответствуют данным, переданным в PUT.
