# BUG-002 — Не фильтруется список бронирований по дате выезда

**Severity:** Средняя  
**Priority:** Средний  
**Status:** Открыт  
**Method:** `GET`  
**Endpoint:** `/booking?checkout={checkout}`

## Краткое описание
При запросе списка бронирований с определенной датой выезда возвращается полный массив всех бронирований без фильтрации.

## Предусловия
- Restful Booker API доступен.

## Тестовые данные
Не требуются

## Шаги воспроизведения
1. Отправить `GET /booking?checkout={checkout}`, где {checkout} это дата выезда по любому их созданных ранее бронирований.
2. Проверить HTTP status code.
3. Проверить response body.

## Ожидаемый результат
В теле ответа содержится массив бронирований только с указанной датой выезда.

## Фактический результат
API возвращает 200 OK и возвращает полный массив всех бронирований без фильтрации по дате выезда.

## Связанный тест-кейс
