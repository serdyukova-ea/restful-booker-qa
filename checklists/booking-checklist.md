# Booking API — Checklist

## 1. Авторизация — `POST /auth`

- [ ] Авторизация с валидными учётными данными
- [ ] Проверка HTTP status code
- [ ] Проверка наличия токена в response
- [ ] Авторизация с неверным username
- [ ] Авторизация с неверным password
- [ ] Авторизация с пустым username
- [ ] Авторизация с пустым password
- [ ] Авторизация с отсутствующими обязательными полями

---

## 2. Создание бронирования — `POST /booking`

### Позитивные сценарии

- [ ] Создание бронирования с валидными данными
- [ ] Создание бронирования с минимальным набором данных
- [ ] Создание бронирования со всеми доступными полями
- [ ] Проверка HTTP status code успешного запроса
- [ ] Проверка наличия `bookingid` в response
- [ ] Проверка соответствия переданных данных данным в response
      
### Негативные сценарии

- [ ] Создание бронирования с отсутствием обязательного поля
- [ ] Создание бронирования с невалидным значением в поле
- [ ] Создание бронирования с некорректным типом поля

### Обязательные поля

- [ ] Отсутствует `firstname`
- [ ] Отсутствует `lastname`
- [ ] Отсутствует `totalprice`
- [ ] Отсутствует `depositpaid`
- [ ] Отсутствует `bookingdates`
- [ ] Отсутствует `checkin`
- [ ] Отсутствует `checkout`

### Валидация данных

- [ ] Пустое значение `firstname`
- [ ] Пустое значение `lastname`
- [ ] Отрицательное значение `totalprice`
- [ ] Некорректный тип `totalprice`
- [ ] Некорректный тип `depositpaid`
- [ ] Некорректный формат даты
- [ ] `checkout` раньше `checkin`
- [ ] Одинаковые даты `checkin` и `checkout`
- [ ] Граничные значения `totalprice`
- [ ] Пустое значение `additionalneeds`
